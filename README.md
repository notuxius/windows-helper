# Windows Helper

Windows Helper is an AutoHotkey v1 tray app with three global shortcuts.

| Shortcut | Action |
| --- | --- |
| Ctrl+Alt+A | Toggle the active window between borderless fullscreen and its previous size. |
| Scroll Lock | Open the Windows screen snipping overlay. |
| Pause | Request sleep through the Windows power menu. |

Download `WindowsHelper.exe` from [Releases](https://github.com/notuxius/windows-helper/releases) and run it. To run the source, open `Code.ahk` with AutoHotkey v1.
